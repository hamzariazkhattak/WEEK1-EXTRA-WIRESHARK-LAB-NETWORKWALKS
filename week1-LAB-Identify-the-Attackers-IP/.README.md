# Wireshark SOC Lab – Identify the Attacker's IP

## 📌 Project Overview

This repository documents my hands-on experience completing the **Wireshark SOC Lab – Identify the Attacker's IP**, provided by **NETWORKWALKS** as part of my Cybersecurity Internship.

The purpose of this lab was to develop practical network traffic analysis skills using Wireshark, understand suspicious network activities, identify potential attacks, and investigate network communication from a SOC analyst's perspective.

Through different practical tasks, I explored packet captures, analyzed network protocols, examined TCP connection behavior, and learned how to recognize indicators of malicious network activity.

## 🎯 Lab Objectives

- Understand network packet capture and analysis.
- Identify source and destination IP addresses.
- Analyze suspicious network traffic.
- Understand TCP connection establishment and termination.
- Identify open and closed TCP ports.
- Understand TCP flags such as SYN, ACK, FIN, and RST.
- Analyze DNS, ARP, ICMP, TCP, and HTTP traffic.
- Recognize port scanning activities.
- Develop fundamental SOC investigation skills.

## 🔍 Practical Tasks & Activities

During this lab, I worked on multiple network investigation exercises, including:

### 1. Network Traffic Analysis
- Examined captured network packets.
- Identified source and destination addresses.
- Analyzed different network protocols.
- Inspected packet information and communication patterns.

### 2. DNS Traffic Analysis
- Examined DNS queries and responses.
- Observed domain name resolution.
- Identified DNS communication between hosts.

### 3. TCP Packet Analysis
- Investigated TCP connection requests and responses.
- Studied SYN, ACK, FIN, and RST flags.
- Understood TCP connection behavior.

### 4. Open and Closed Port Identification
- Analyzed TCP responses from different ports.
- Identified RST, ACK responses.
- Learned how closed ports respond to connection attempts.

### 5. Port Scanning Detection
- Investigated connection attempts targeting multiple ports.
- Learned how port scanning works.
- Identified suspicious traffic patterns associated with reconnaissance activities.

### 6. Attacker Identification
- Examined suspicious network communication.
- Studied traffic patterns to recognize potential attacks.
- Practiced identifying indicators that can help determine an attacker's IP address.
